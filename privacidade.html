Política de Privacidade · Mensagem da Paróquia

Última atualização: 19 de novembro de 2026

Este aplicativo ("App") é uma ferramenta interna usada exclusivamente pelo criador do canal Mensagem da Paróquia (@mensagemdaparoquia).

1. Quais dados o App acessa

Com a autorização do próprio criador, o App acessa apenas:

- Perfil básico do TikTok (`user.info.basic`): identificador da conta, nome de exibição e foto do perfil. Usado só para confirmar em qual conta o App está publicando. - Permissão de publicação (`video.publish`, `video.upload`): usada para enviar os vídeos do canal.

2. O que o App não faz com os dados

  • Não coleta dados de outras pessoas.
  • Não vende, compartilha ou transfere dados para terceiros.
  • Não acessa mensagens, contatos ou qualquer outro dado da conta.
  • Não usa os dados para publicidade.

3. Onde os dados ficam

O token de acesso fica somente no computador do criador, em um arquivo local protegido, e nunca é enviado para servidores de terceiros.

4. Retenção

O token é mantido enquanto o criador usar o App. Ele é descartado quando o acesso é revogado pelo próprio criador nas configurações do TikTok.

5. Seus direitos

O criador pode revogar o acesso do App a qualquer momento em Configurações do TikTok → Segurança e permissões → Gerenciar permissões do app.
